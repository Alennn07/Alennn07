## 👾 About

I build with Python, Next.js, and Supabase, and I like projects that start from a real problem: something that didn't work on my machine, or didn't work for the people I wanted to use it.

My approach is simple. Get it working, test it, document it, and open it up so other people can build on it. A project isn't finished until someone else can run it without asking me how.

## 🧭 Principles

- **Start with a real problem.** If it annoyed me, it probably annoys someone else.
- **Make setup boring.** Good defaults, clear config, and instructions that work on Windows too.
- **Test the thing.** Automated tests and CI beat "works on my machine."
- **Document as you go.** Future contributors (and future me) shouldn't have to guess.
- **Share it.** Open the work up and let people take it further.
